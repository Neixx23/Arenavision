# ArenaVision

Aplicación experimental en Python/Streamlit para analizar imágenes de arena silícica, medir granos y estimar una composición visual. Permite ingresar resultados reales de laboratorio y calcular un consumo teórico de reactivo.

## Ejecución

```powershell
python -m streamlit run app.py
```

Instale dependencias con:

```powershell
python -m pip install -r requirements.txt
```

## Uso seguro

La salida visual no reemplaza XRF, ICP, XRD ni ensayos de lixiviación. Las estimaciones de ácido son balances estequiométricos simplificados, no instrucciones operativas. Cualquier prueba debe hacerse mediante procedimientos validados, ventilación, EPP y gestión segura de residuos.
